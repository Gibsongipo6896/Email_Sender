PYTHON EMAIL SENDER version 1.0 ~ Gibson Programmer
Python Email Sender is a lightweight script designed for ease of use, allowing users to send customized emails with a specific sender name. Utilizing only inbuilt libraries like smtplib, this script offers a simple solution for automating personal messages or notifications, making it ideal for developers looking to enhance their projects with email functionality.

Features:
Custom Sender Name: Personalize the sender name for a more authentic touch.
Flexible Email Content: Easily modify the subject and body of the email.
Inbuilt Libraries: No external dependencies required, using only standard Python libraries.
Installation:
Prerequisites: Make sure you have Python installed on your system. You can download it from the official Python website.
Download the Script: Clone or download the repository containing the python_email_sender.py script.
Run the Script: Open your terminal or command prompt, navigate to the script's directory, and execute it using:
bash


    python python_email_sender.py
